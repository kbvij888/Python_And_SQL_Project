# Python and SQL Authentication System

This project is a simple authentication system built using Python and SQL. It allows users to register, log in, and securely manage credentials using a backend database.

## Features
- User registration with validation
- Secure login system
- SQL database integration
- Error handling and input sanitization

## Tech Stack
- Python 3.x
- SQLite / MySQL (update based on what you used)
- VS Code

## How to Run

1. Open a terminal or command prompt.
2. Navigate to the project folder.
3. Run the following command:

python main.py

4. When the program starts, follow the instructions shown on the screen.

Example output:

Enter username:
Enter password:
Login successful!
